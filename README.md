# Система управления заявками жильцов

## Предметная область
Жилищно-коммунальное хозяйство (ЖКХ), управление недвижимостью, сервисное обслуживание.

## Основные сущности
- Жилец (Tenant)
- Заявка (Request)
- Категория заявки (Категория/Тип проблемы)
- Исполнитель (Worker)

## Основные функции
1. Регистрация новой заявки от жильца с указанием типа проблемы.
2. Автоматическое определение приоритета заявки на основе её типа.
3. Расчет предварительной стоимости или сроков выполнения (с учетом срочности).
4. Просмотр текущего статуса заявки.
